# ✉️ Envelope Budgeter & Financial Tracker

A dynamic, web-based budgeting application designed to help users allocate their monthly income into custom spending envelopes (categories) such as Rent, Food, Utilities, and Entertainment. Built as part of a freeCodeCamp workshop project.

## ✨ Features

- **Dynamic Income & Expense Tracking:** Real-time budget calculations based on user input.
- **Custom Budget Categories:** Flexible envelope system to organize income across various spending categories.
- **Over-Budget Alerts:** Automated remaining balance updates and visual warnings when expenses exceed income.
- **Interactive Form Handling:** Robust input validation and dynamic DOM manipulation for seamless user experience.
- **Responsive Layout:** Structured UI designed to work across standard desktop and mobile screens.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup and structure.
- **CSS3:** Custom layout styling, dynamic state indicators, and responsive components.
- **JavaScript (ES6+):** Application state management, DOM manipulation, form validation, and event handling.
